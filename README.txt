Финальный патч overlay.html с настройками бейджей и ролей
Как использовать:
1) Размести overlay.html и fonts.css на публичном сайте.
2) В Streamelements добавь Overlay HTML и укажи URL overlay.html.
3) CSV источник:
   - файл: sample_data.csv (пример внутри /home/user/pixel-chat)
   - схема: author,message,role
4) Загрузи roles.json через Load Roles (по желанию) и подкл ادا
